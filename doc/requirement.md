# 智能员工评价分析与提升建议系统（AI Performance Coaching Assistant）

## 项目简介

本项目旨在通过读取员工绩效评价数据，结合大语言模型（LLM），自动生成多维度、个性化的能力提升建议。主要解决 HR 在员工评估与辅导建议撰写上的效率与质量问题。

---

## 项目目标

- 从 Excel / CSV / 数据库中读取员工评价内容；
- 按照预设的多个能力维度，生成个性化提升建议；
- 利用 AI 自动完成建议撰写，提升效率与参考价值；
- 支持结构化输出，可用于报告生成或系统集成。

---

## Prompt 示例设计

**支持维度：**

- 沟通能力
- 执行力
- 学习力
- 团队合作
- 领导潜力

**Prompt 模板示例：**

```jinja2
你是一名资深人力资源专家，请根据以下员工的评价内容，结合沟通能力、执行力和团队合作这几个维度，生成三条具体的能力提升建议。评价内容如下：

{{ employee_comments }}

要求：
- 每条建议不超过100字；
- 建议应具体、可执行，适合初中级员工参考。
